# 网页版 CS 风格 FPS

一个开箱即用、完全原创的网页 FPS 游戏，致敬经典 CS1.6 的回合制玩法：
匪徒（T）进攻下包 vs 警察（CT）防守拆包，5v5（你 + 8 个机器人），带完整经济系统与购买菜单。

> 本作是原创致敬作品，与 Valve 无关，不使用任何 CS1.6 原始素材；地图、贴图、模型、音效全部程序化生成。

## 开箱即用

直接用现代浏览器（Chrome / Edge / Firefox）打开 `index.html` 即可，无需安装任何东西。

页面会从 CDN 加载 Three.js（三路备选：jsDelivr → unpkg → cdnjs），因此首次打开需要联网。
之后所有游戏内容均为本地文件，可以断网游玩（只需 CDN 缓存成功后刷新一次）。

也可以本地起一个静态服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 玩法

- 每回合：5 秒冻结购买 → 15 秒购买时间 → 150 秒对战。
- T 携带炸弹前往 A 区按住 E 安装，45 秒后爆炸获胜；CT 需在炸弹爆炸前按住 E 拆弹（拆弹钳减半时间）。
- 全歼对方、拆弹成功、炸弹爆炸或时间耗尽都会结束回合。
- 击杀 +$300（爆头 +$50），安装/拆除炸弹 +$300，回合胜利 +$3000，失败 +$1500，资金上限 $16000。
- 购买菜单：防弹衣、防弹头盔、P9、AK-47（T）、M4（CT）、AWP、拆弹钳（CT）。
- 机器人每回合自动购买、寻路、索敌、下包与拆包；回合结束双方自动重生。

## 已知说明

- 本作是简化致敬版，武器外观与数值均为原创设计，不包含 CS1.6 的官方地图、模型与音效。
- 若 Three.js CDN 加载失败，页面会给出提示，检查网络后刷新即可。
- 支持本地 `file://` 直接双击打开（无需服务器）。

## 故障排查

- 更新版本后如果还看到旧行为（如黑屏但有 HUD），请强制刷新：`Ctrl + F5`（或清除浏览器缓存），避免浏览器继续使用旧的 js 文件。
- 运行时如果出现任何异常，页面左下角会弹出红色错误横幅，把上面的报错信息发给我即可快速定位。
